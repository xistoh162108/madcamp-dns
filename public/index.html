참고

  • 이름에 @를 넣으면 내 도메인 자체에 연결됩니다. www, api 같은 이름은 그 앞에 붙습니다.
  • Vercel은 CNAME cname.vercel-dns.com, proxy 끔. Vercel 프로젝트 Domains에도 같은 주소를 추가해야 합니다.
  • 같은 이름에 CNAME과 A를 같이 둘 수 없습니다. 타입을 바꾸려면 지우고 다시 추가해 주세요.
  • 로그인은 12시간 유지되고, 탭을 닫으면 로그아웃됩니다.
