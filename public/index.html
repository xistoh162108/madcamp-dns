참고

  
    
    
  • 이름에 @를 넣으면 고른 서브도메인 자체에 연결됩니다. www, api 같은 이름은 그 앞에 붙습니다.
    • 
    
  • DNS는 주소를 다른 곳으로 이어주는 것이지 HTTP 리다이렉트가 아닙니다. 브라우저 주소창은 내 도메인 그대로 유지됩니다.
    • 
    
  • Vercel은 CNAME cname.vercel-dns.com, proxy 끔. Vercel 프로젝트 Domains에도 같은 주소를 추가해야 합니다.
    • 
    
  • 같은 이름에 CNAME과 A를 같이 둘 수 없고, 터널에 쓰는 주소에는 레코드를 따로 만들 수 없습니다.
    • 
    
  • 레코드 타입은 바꿀 수 없습니다. 지우고 다시 추가해 주세요.
    • 
    
  • 목록의 주소를 누르면 새 탭에서 열립니다. 방금 바꾼 레코드는 반영까지 몇 분 걸릴 수 있습니다.
    • 
    
  • 로그인은 12시간 유지되고, 탭을 닫으면 로그아웃됩니다.
    •
